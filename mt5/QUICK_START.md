# ⚡ XAUUSD Pro Trading Tool - クイックスタートガイド

## 5分で始める XAUUSD 自動シグナル

### ステップ 1: ファイルダウンロード（2分）
```
GitHub から clone または zip download:
├── XAUUSD_ProTrader_v1.mq5        ← EA メイン
└── XAUUSD_Professional_Signal.mq5 ← インジケータ
```

### ステップ 2: MT5 に配置（1分）
Windows の場合：
```
C:\Users\[ユーザー名]\AppData\Roaming\MetaQuotes\Terminal\[ID]\MQL5\
├── Experts\Advisors\         ← EA を置く
└── Indicators\               ← インジケータを置く
```

macOS の場合：
```
~/Library/Application Support/MetaQuotes/Terminal/[ID]/MQL5/
```

### ステップ 3: コンパイル（1分）
1. MT5 を開く
2. Ctrl + Shift + F4（メタエディタ）
3. ファイル → 開く → XAUUSD_ProTrader_v1.mq5
4. **F5 キス** で コンパイル

### ステップ 4: チャートに設定（1分）
1. XAUUSD チャートを開く
2. ナビゲータ → エキスパートアドバイザー
3. XAUUSD_ProTrader_v1 をチャートにドラッグ
4. **OK** をクリック

### ✅ 完了！
シグナルが表示されたら成功です！

## 🚨 シグナルが表示されない場合

### チェックリスト
- [ ] EA が正常に起動している？（左上に「スマイリー」顔があります）
- [ ] インジケータがチャートに表示されている？
- [ ] インジケータハンドルが正常？（ターミナルのエラー確認）
- [ ] XAUUSD チャートが正しく開いている？
- [ ] 十分な足数がある？（最低 100 足以上）

### 再起動手順
```
1. EA を停止（左上の x ボタン）
2. インジケータ を削除
3. MT5 を完全に再起動
4. 再度 EA とインジケータを設定
```

## ⚙️ カスタマイズのコツ

### RSI パラメータを変更
```
RSI_Period を短くする（例: 10）
→ より敏感に反応（偽信号増加）

RSI_Period を長くする（例: 21）
→ より安定的（反応が遅い）
```

### EMA で トレンド感度を変更
```
EMA_Fast を短くする（例: 10）
→ より短期的なトレンド検出

EMA_Slow を長くする（例: 100）
→ より長期的なトレンドに従う
```

### シグナル頻度を変更
```
MinBarsSinceSignal = 3
→ 3 足ごとにシグナル可（多い）

MinBarsSinceSignal = 10
→ 10 足ごとにシグナル（少ない、信頼度高）
```

## 🔐 安全に使うための ルール

1. **必ずデモ口座で検証する** → 最低 1 週間
2. **リアル口座では小額から** → 初月は 1 ロット未満
3. **24/7 監視しない** → 主要時間（EU/US オープン）に集中
4. **GDPなどの重大発表時は避ける** → 予測不可の動き
5. **マネーマネジメント厳守** → 1 トレード = リスク 1~2%

## 📞 FAQ（よくある質問）

**Q1: デモ口座で試してみたいのですが？**
```
A: 可能です。むしろ推奨します。
   MT5 デモ口座 → EA 設定 → 1 週間試してみてください。
```

**Q2: バックテストはできますか？**
```
A: はい。MT5 のストラテジーテスター（View → Strategy Tester）で可能です。
```

**Q3: 過去 1 年間のシグナル履歴を見たいのですが？**
```
A: ターミナル → ジャーナル タブで確認できます。
   または、バックテストで検証してください。
```

**Q4: パラメータを自動最適化できますか？**
```
A: MT5 のストラテジーテスターで「最適化」ボタンを使用。
   ただし、過度な最適化（オーバーフィッティング）に注意してください。
```

**Q5: スマートフォン版 MT5 でも動作しますか？**
```
A: EA は動作しません（PC 版 MT5 のみ）。
   ただし、通知は受け取れます。
```
