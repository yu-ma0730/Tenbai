# XAUUSD Professional Trading Tool
## MT5 用 ゴールド取引自動シグナルツール

![Version](https://img.shields.io/badge/version-1.0-blue)
![Platform](https://img.shields.io/badge/platform-MetaTrader5-brightgreen)

### 📊 概要

このツールは、専業トレーダーレベルの XAUUSD（ゴールド/米ドル）自動トレーディングシグナルを生成します。
リアルタイムで買い・売りシグナルを検出し、チャートアラートと通知で即座に知らせます。

---

### ✨ 主要機能

#### 1. **リアルタイムシグナル生成**
- RSI（相対力指数）による買われすぎ/売られすぎ判定
- MACD による トレンド確認と反転検出
- 移動平均線（EMA）によるトレンド方向確認
- サポート/レジスタンスレベルの自動計算

#### 2. **複合指標ロジック**
```
BUY シグナル条件:
✓ RSI < 30（売られすぎ）
✓ MACD > Signal Line（強気交差）
✓ Close Price < Fast EMA（下降から回復）
✓ Fast EMA > Slow EMA（上昇トレンド）

SELL シグナル条件:
✓ RSI > 70（買われすぎ）
✓ MACD < Signal Line（弱気交差）
✓ Close Price > Fast EMA（上昇から下降）
✓ Fast EMA < Slow EMA（下降トレンド）
```

#### 3. **多重通知システム**
- MT5 チャートアラート（音声）
- モバイル通知（MT5 スマートフォンアプリ）
- ログ記録（ターミナル → ジャーナル）

#### 4. **専業トレーダー向け設計**
- 誤信号を最小化する多要件フィルタリング
- 信号間の最小間隔設定
- 市場の条件に応じたパラメータ調整可能

### 🛠️ セットアップ方法

#### ステップ 1: ファイルを MT5 に配置
```
MetaTrader5 インストールフォルダ/
├── MQL5/
│   ├── Experts/
│   │   └── Advisors/
│   │       └── XAUUSD_ProTrader_v1.mq5      ← EA メイン
│   └── Indicators/
│       └── XAUUSD_Professional_Signal.mq5   ← インジケータ
```

#### ステップ 2: MT5 で コンパイル
1. MetaTrader 5 を開く
2. Ctrl + Shift + F4 で「メタエディタ」を開く
3. ファイル → 開く で上記の .mq5 ファイルを開く
4. F5 キーで コンパイル（右上に「コンパイル成功」と表示）

#### ステップ 3: EA をチャートに設定
1. XAUUSD チャートを開く（推奨時間足：H1 または H4）
2. 左パネルの ナビゲータ → エキスパートアドバイザー
3. 「XAUUSD_ProTrader_v1」をダブルクリック またはドラッグしてチャートに載せる

#### ステップ 4: インジケータ を追加
1. 挿入 → インジケータ → カスタム → XAUUSD_Professional_Signal
2. シグナル表示とともに RSI/MACD/EMA が表示されます

### ⚙️ パラメータ設定

#### 推奨設定（デイトレード・H1 時間足）

```
RSI パラメータ:
  RSI_Overbought = 70.0  （買われすぎ閾値）
  RSI_Oversold = 30.0    （売られすぎ閾値）
  RSI_Period = 14        （標準値）

MACD パラメータ:
  MACD_Fast = 12         （短期 EMA）
  MACD_Slow = 26         （長期 EMA）
  MACD_Signal = 9        （シグナルライン）

EMA パラメータ:
  EMA_Fast = 20          （短期トレンド）
  EMA_Slow = 50          （長期トレンド）

シグナルフィルタ:
  MinBarsSinceSignal = 3 （シグナル間の最小足数）
  Risk_Percent = 2.0     （1 トレード当たりリスク %）

通知設定:
  UseSoundAlert = true   （チャートアラート音）
  UseNotification = true （モバイル通知）
```

#### スイングトレード用設定（H4 時間足）
```
EMA_Fast = 30
EMA_Slow = 100
MinBarsSinceSignal = 5
```

### 💡 専業トレーダーの使用方法

#### 1. **リアルタイムモニタリング**
- EA を起動して、シグナルを待機
- モバイルアプリで通知を受け取る
- 急激な市場変動時は手動で確認

#### 2. **シグナル確認**
- チャートの矢印でシグナルを視覚確認
- インジケータ値（RSI/MACD/EMA）で強度を判定
- サポート/レジスタンスで エントリー/エグジット ポイント決定

#### 3. **リスク管理**
```
推奨リスク管理:
- 1 トレード = リスク 1~2%
- SL（ストップロス）= 直近スイング安値/高値
- TP（テイクプロフィット）= リスク:リワード = 1:2 以上
```

#### 4. **パラメータ調整**
- 市場環境に応じて RSI/EMA パラメータを微調整
- 通常のフィルタ（3 足）で十分だが、高勝率重視なら 5 足に増加
- 過度にパラメータ変更しないこと（最適化の落とし穴）

### 🔍 トラブルシューティング

| 問題 | 原因 | 解決方法 |
|------|------|--------|
| シグナルが表示されない | インジケータが表示されていない | ナビゲータからインジケータを再度ドラッグ |
| 音が出ない | UseSoundAlert = false に設定 | EA の設定で UseSoundAlert = true に変更 |
| 通知が来ない | モバイル通知設定が無効 | MT5 スマートフォンアプリで通知を有効化 |
| エラーが出る | インディケータハンドルが無効 | MT5 を再起動し、再度コンパイル |
| 誤信号が多い | パラメータが市場に合わない | EMA_Slow を増やす、または RSI 周期を長くする |
