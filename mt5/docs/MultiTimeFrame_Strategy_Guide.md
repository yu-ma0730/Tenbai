## <a name="基礎"></a>🏛️ マルチタイムフレーム分析の基礎

### なぜマルチタイムフレーム？

```
単一時間足分析の問題：
❌ ノイズが多い（小さな価格変動に反応しすぎ）
❌ トレンドの方向性が不明確
❌ 誤信号が多い（60~70%は損失）

マルチタイムフレーム分析の利点：
✅ トレンドの強さを複数視点で確認
✅ 誤信号を大幅削減（勝率 60~70%）
✅ より高い利益率（リスク:リワード = 1:2以上）
✅ 専業トレーダーの標準手法
```

## <a name="3層構造"></a>🏗️ 3層構造トレーディングシステム

### システム概要

```
┌─────────────────────────────────────┐
│  D1（日足）= 大局観・戦略層         │
│  大きなトレンド方向を決定            │
│  保有期間：数日～数週間              │
└─────────────────────────────────────┘
           ↓ 確認
┌─────────────────────────────────────┐
│  H4（4時間足）= 戦術層              │
│  中期トレンド・エントリータイミング  │
│  保有期間：数時間～1日               │
└─────────────────────────────────────┘
           ↓ 実行
┌─────────────────────────────────────┐
│  H1（1時間足）= 実行層              │
│  正確なエントリーポイント            │
│  保有期間：数時間～半日              │
└─────────────────────────────────────┘
```

## <a name="実践"></a>💡 実践的なエントリー/エグジット方法

### ステップ 1: D1（日足）でトレンド確認

```
D1 チャートを開く
↓
EMA(20) と EMA(50) の位置関係を確認

上昇トレンド判定：
✅ EMA(20) > EMA(50)
✅ ローソク足が EMA(20) より上
✅ 直近 3～5 本の足が上昇傾向

下降トレンド判定：
✅ EMA(20) < EMA(50)
✅ ローソク足が EMA(20) より下
✅ 直近 3～5 本の足が下降傾向

フラット（トレンドなし）：
❌ EMA が交差している
❌ ローソク足が EMA(20) 周辺でウロウロ
→ この場合はトレード見送り推奨
```

### ステップ 2: H4（4時間足）で方向性を確認

```
D1 で上昇トレンドが確認できた場合：
→ H4 チャートを開く

チェック項目：
1. EMA(20) > EMA(50)？ ← D1 と同じ方向か
2. 直近サポートレベルはどこ？ ← ストップロス設定用
3. MACD がどの状態？ ← 強気か弱気か
4. RSI がどの水準？ ← 極度に買われすぎ/売られすぎか

H4 と D1 が同じ方向 → 信頼度 ★★★★★ （最高）
H4 が D1 と逆方向 → 要注意（見送り検討）
```

### ステップ 3: H1（1時間足）でエントリータイミング

```
D1（上昇トレンド） + H4（確認済み）
↓
H1 チャートを開く
↓
以下の条件すべてが満たされるまで待機：

1️⃣ RSI < 30（売られすぎ）
   → 反発の準備ができている

2️⃣ MACD > Signal Line（強気転換）
   → 上昇シグナル点灯

3️⃣ ローソク足が支持線でバウンス
   └─ ピンバー（下ヒゲ長い）
   └─ エンゴルフィング（買い）
   └─ インサイドバー（次の足の注目）

4️⃣ ボリューム確認
   → 直前の足のボリュームが増加

全て揃ったら → ✅ BUY エントリー！
```

## 📊 エントリー・エグジットルール

### BUY エントリー例（実例）

```
日時：2024年7月21日 14:30

【D1 分析】
EMA(20): 2430.50
EMA(50): 2420.00
→ EMA(20) > EMA(50) = 上昇トレンド ✅
最近のサポート: 2425.00

【H4 分析】
現在: 2432.00
EMA(20): 2430.00
EMA(50): 2425.00
→ EMA(20) > EMA(50) = 上昇トレンド確認 ✅
MACD: 正転（強気）✅

【H1 分析】
現在: 2430.50
RSI: 28（売られすぎ）✅
MACD: 0.0045（信号線超えたばかり）✅
直前足: ピンバー（下ヒゲ）✅
ボリューム: 前足の 2 倍✅

→ 全条件満たす！

【エントリー決定】
エントリー価格: 2430.50
ストップロス: 2425.00（D1 サポート）
テイクプロフィット: 2440.00（リスク:リワード = 1:2）

リスク計算:
 損失額 = 2430.50 - 2425.00 = 5.50 USD
 利益額 = 2440.00 - 2430.50 = 9.50 USD
 リスク:リワード = 5.50:9.50 = 1:1.7 ✅ (良好)
```

### エグジットルール

```
【利確（テイクプロフィット）】
方法 1: 事前設定した TP に達したら利確
方法 2: H4 のレジスタンスに到達したら利確
方法 3: RSI > 70 になったら利確（売られすぎ解消）

【損切（ストップロス）】
必ず以下のいずれかで損切：
・D1 の直近サポート/レジスタンス破節
・ローソク足が H4 EMA(20) を明確に割り込む
・H1 RSI が 50 未満に低下（トレンド転換兆候）

【トレーリングストップ（推奨）】
利益が乗ったら、SL を上方に移動：
損失時: 使わない
+50 pips 利益: SL を +20 pips まで上げる
+100 pips 利益: SL を +50 pips まで上げる
→ 利益確定のチャンスを最大化
```

## <a name="事例"></a>📈 実践事例分析

### ケース 1: 成功トレード（上昇トレンド）

```
【相場状況】
月曜 08:00 - D1 上昇トレンド中
最近サポート: 2420.00
前週高値: 2450.00

【エントリー】
月曜 14:30
H1: RSI = 25（売られすぎ）+ MACD 正転
→ ENTRY: 2428.50

【管理】
SL: 2420.00（D1 サポート）
TP1: 2438.50（リスク 1:1）
TP2: 2448.50（リスク 1:2.5）

【推移】
15:30 → 2432.00（+350 pips）TP1 で半分利確
16:30 → 2440.00（+1150 pips）H4 レジスタンス到達
→ 残り半分も利確

【結果】
利益: 750 pips（平均）
リスク: 850 pips
勝率: 1 回のトレードで 2 週間分の利益
```

### ケース 2: 注意が必要な場面（トレンド転換）

```
【D1 分析】
上昇トレンド中だが、RSI > 75（過度な買われすぎ）
MACD が信号線より下がり始めた = 弱気転換兆候

【H4 分析】
まだ上昇トレンドに見えるが...
直近高値で反発始まる = 上値限界か

【H1 分析】
RSI が 70 超えで買いシグナル点灯
ピンバー（上ヒゲ長い）出現

【判断】
⚠️ 危険信号: 複数時間足で弱気転換兆候
✅ 正解: このシグナルでエントリー見送り
結果: この後 30 pips 下落 → 見送ったのは正解

【教訓】
全ての信号が揃っていることが最重要
1 つでも疑わしい → 見送るべき
```

## <a name="ミス"></a>⚠️ よくあるミスと対策

### ミス 1: 単一時間足のみで判断

```
❌ 誤り例：
「H1 で RSI < 30 だからエントリー」
→ しかし H4 は下降トレンド中
→ 結果：逆行して損失

✅ 対策：
必ず H4/D1 でトレンド確認
H4/D1 と H1 が同じ方向のみエントリー
勝率が大幅に向上（55% → 65% ）
```

### ミス 2: 急いでエントリー

```
❌ 誤り例：
「RSI < 30 見えた！すぐエントリー」
→ 急いでボタン押す
→ MACD はまだ信号線以下
→ 結果：すぐに損切

✅ 対策：
複数条件が**全て**揃うまで待機
「黄金の待機」こそが専業トレーダー
時間に余裕を持つ（焦りは敵）
```

### ミス 3: ストップロスが大きすぎる

```
❌ 誤り例：
「ストップロス 200 pips で OK」
→ 1 回の損失が大きい
→ 3 回の損失で総資金の 30% 失う

✅ 対策：
SL は常に D1 のサポート/レジスタンス直下
通常 50～100 pips
1 トレード = 総資金の 1~2% リスク
```

### ミス 4: 高すぎるレバレッジ

```
❌ 誤り例：
「50 倍レバレッジで 10 ロット」
→ 小さな変動で口座吹き飛ぶ
→ 感情的なトレード → さらに大損

✅ 対策：
初心者: 5~10 倍レバレッジ
中級: 10~20 倍
上級: 20 倍程度
リスク > リターンは絶対 NG
```
