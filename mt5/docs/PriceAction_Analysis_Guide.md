## <a name="プライスアクションとは"></a>💡 プライスアクションとは？

### 定義

```
プライスアクション = 価格と時間だけで判断するトレーディング手法

特徴：
✅ インジケータに頼らない
✅ ローソク足の形状から市場心理を読む
✅ 専業トレーダーの最も信頼度の高い方法
✅ 過度な最適化の心配がない

従来のテクニカル指標：
RSI, MACD, EMA など
→ 遅行指標（市場の後を追いかける）
→ 誤信号が多い

プライスアクション：
ローソク足の形状そのもの
→ リアルタイムの市場心理
→ 最も先行している
```

### なぜプライスアクションが重要か？

```
シナリオ：買いシグナルが出ている
───────────────────────────────

インジケータだけ：
RSI < 30 ✅
MACD 正転 ✅
→ エントリー
→ 結果：下落して損失 ❌

プライスアクション確認：
RSI < 30 ✅
MACD 正転 ✅
しかし、ローソク足の形は？
└─ 長い上ヒゲで終わった = 売り圧力が強い
→ エントリー見送り
→ その後、予想通り下落
→ 損失回避 ✅

結論：
プライスアクションがすべてのトレードの最終判定
インジケータはあくまで補助
```

## <a name="基本パターン"></a>🔍 基本パターン

### 1️⃣ ピンバー（Pin Bar）

#### 概要
```
定義：
・1 本のローソク足
・片方のヒゲが非常に長い
・本体（実体）が小さい
・反対側のヒゲが短い

意味：
買い手（売り手）が押し込もうとしたが、
強い売り（買い）圧力で反発された
= 反転のシグナル
```

#### 買いピンバー（Bull Pinbar）

```
形状：
┌─────────────┐
│             │  ← 上ヒゲ（短い）
│  ██████     │  ← 本体（小さい、白）
│  ██████     │
│             │
│             │
│             │
│             │  ← 下ヒゲ（長い）超重要！
└─────────────┘

特性：
✅ 下ヒゲ > 本体 × 2～3 倍
✅ 本体は白ローソク（上昇）
✅ 上ヒゲは短い
✅ 前足は下降足（売り圧力あり）

市場心理：
「売り手が押し込みます」
        ↓
「あ、買い手が反発した」
        ↓
「チャンス！買いましょう」
        ↓
ローソク足が立ち上がる

取引方法：
エントリー：下ヒゲの下に SL を置いて、BUY
ストップロス：下ヒゲより下 10～20 pips
テイクプロフィット：直近レジスタンスまで
```

#### 売りピンバー（Bear Pinbar）

```
形状：
┌─────────────┐
│             │  ← 上ヒゲ（長い）超重要！
│             │
│             │
│     ██████  │  ← 本体（小さい、黒）
│     ██████  │
│             │  ← 下ヒゲ（短い）
└─────────────┘

特性：
✅ 上ヒゲ > 本体 × 2～3 倍
✅ 本体は黒ローソク（下降）
✅ 下ヒゲは短い
✅ 前足は上昇足（買い圧力あり）

市場心理：
「買い手が上げようとします」
        ↓
「あ、売り手が反発した」
        ↓
「チャンス！売りましょう」
        ↓
ローソク足が下がる

取引方法：
エントリー：上ヒゲの上に SL を置いて、SELL
ストップロス：上ヒゲより上 10～20 pips
テイクプロフィット：直近サポートまで
```

### 2️⃣ エンゴルフィング（Engulfing）

#### 概要
```
定義：
・2 本のローソク足の組み合わせ
・前足：方向性が決まった足
・後足：前足を完全に「飲み込む」

意味：
前足の決定が覆される
= トレンド転換のシグナル（特に強力）
```

#### 買いエンゴルフィング

```
形状：
前足：          後足：
┌───────┐     ┌─────────┐
│  ███  │     │         │
│  ███  │     │  █████  │
│  ███  │     │  █████  │
│  ███  │     │  █████  │
└───────┘     │  █████  │
（黒い足）      │  █████  │
               └─────────┘
               （白い足、前足より大きい）

特性：
✅ 前足：黒い（下降）
✅ 後足：白い（上昇）
✅ 後足の高値 > 前足の高値
✅ 後足の安値 < 前足の安値
✅ 完全に包み込む

信頼度：⭐⭐⭐⭐⭐ 最高！

取引方法：
エントリー：後足の高値より上で BUY
ストップロス：後足の安値より下
テイクプロフィット：直近レジスタンス
```

#### 売りエンゴルフィング

```

前足：          後足：
┌───────┐     ┌─────────┐
│  ███  │     │  █████  │
│  ███  │     │  █████  │
│  ███  │     │  █████  │
│  ███  │     │  █████  │

└───────┘     │  █████  │
（白い足）      └─────────┘
               （黒い足、前足より大きい）

特性：
✅ 前足：白い（上昇）

✅ 後足の安値 < 前足の安値
✅ 後足の高値 > 前足の高値
```

### 3️⃣ インサイドバー（Inside Bar）

#### 概要
```
定義：
・2 本のローソク足の組み合わせ
・前足の範囲内に後足が完全に収まる
・ボラティリティが収縮している

意味：
力士が相撲を取る前に低く構える
= 次の大きな値動きの準備
```

#### パターン図

```
前足：          後足：
┌─────────┐
│         │
│  █████  │   ┌───┐
│  █████  │   │ █ │  ← インサイドバー
│  █████  │   │ █ │    前足の中に収まる
│  █████  │   └───┘
│         │
└─────────┘

特性：
✅ 前足の高値 > 後足の高値
✅ 前足の安値 < 後足の安値
✅ 後足は小さい（ボラティリティ低）

信頼度：⭐⭐⭐ （パターン単体では中程度）

使い方（推奨）：
1. インサイドバーの出現を確認
2. その次の足の動きを待つ
3. 大きく上に出たら → BUY
4. 大きく下に出たら → SELL
```

### 4️⃣ 重要な反転パターン

#### ハンマー/ハングマン

```
ハンマー（買い）：         ハングマン（売り）：
┌──────────┐             ┌──────────┐
│          │             │  ████    │
│  ███     │             │  ████    │
│  ███     │             │  ████    │
│          │             │          │
│          │             │          │
│          │             │          │
│          │ ← 長い下ヒゲ │          │ ← 長い上ヒゲ
└──────────┘             └──────────┘

ハンマー：                ハングマン：
・売り圧力が強い         ・買い圧力が強い
・でも買い手が反発       ・でも売り手が反発
→ 底値圏で出現 → 買い    → 天井圏で出現 → 売り
```

#### 複合パターン：ダブルトップ/ダブルボトム

```
ダブルトップ（売り）：     ダブルボトム（買い）：
┌──────────────────┐     ┌──────────────────┐
│ ████        ████ │     │                  │
│ ████        ████ │     │  ███        ███  │
│ ████  ████  ████ │     │  ███  ████  ███  │
│       ████       │     │       ████       │
└──────────────────┘     └──────────────────┘

意味：
・同じレベルで 2 度拒否される
・トレンド反転の強いシグナル
・このレベル（ネックライン）の破節がエントリー

信頼度：⭐⭐⭐⭐ 非常に信頼できる
```

## <a name="トレーニング"></a>📝 パターン認識トレーニング

### 実践トレーニング

```
目標：1 週間で主要パターンを認識できるようになる

Day 1：ピンバーの習得
・過去 100 本の H1 チャートで ピンバーを探す
・購入判定：下ヒゲが本体の 2 倍以上？
・見つけたら矢印を付けてマーク

Day 2：エンゴルフィングの習得
・前足と後足の関係性をチェック
・完全に包み込んでいるか確認
・パターン出現時の翌足の動きを観察

Day 3：インサイドバーの習得
・収縮のパターンを認識
・インサイドバーの直後の大きな動きをマーク
・どちら方向に出やすいか観察

Day 4-5：複合パターン
・ダブルトップ/ボトムを探す
・ハンマー/ハングマンを見つける
・これまでのパターンと組み合わせる

Day 6-7：実践シミュレーション
・新しいチャートを見て、全パターンを判定
・エントリーポイントを決める
・利確/損切ポイントを決める
```

```
✅ D1 上昇トレンド
```

## ⚠️ よくある間違い

### 間違い 1: パターンだけでエントリー

```
❌ 誤り：
「ピンバーが出た！すぐ BUY」
→ D1 は下降トレンド中
→ 逆行して大損

✅ 正解：
ピンバー出現 + D1 上昇トレンド + H4 確認
すべて揃ってからエントリー
```

### 間違い 2: パターンの判定が甘い

```
❌ 誤り：
「下ヒゲが本体と同じくらい → ピンバーか」
→ 本来のピンバーではない
→ 信頼度が下がる

✅ 正解：
「下ヒゲ > 本体 × 2～3 倍」の厳密な基準
判定が曖昧なら見送る
```

### 間違い 3: パターンの出現数

```
❌ 誤り：
「1 日で 10 回のピンバー + すべてエントリー」
→ 連発するピンバーは信頼度が低い
→ 多くが失敗

✅ 正解：
「毎日 1～2 回の厳選シグナルのみ」
質 > 数量
```
