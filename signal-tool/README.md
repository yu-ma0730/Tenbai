# 📊 FX シグナルツール（MT5 インジケータ）

**マルチタイムフレーム分析でFXトレードシグナルを表示するツール**

---

## 🎯 このツールについて

このシグナルツールは、複数のタイムフレーム（4時間足、日足、週足）を同時に分析して、明確なトレードシグナルをMT5のチャートに表示します。

**特徴:**
- ✅ リアルタイムトレンド表示
- ✅ マルチタイムフレーム一致度判定
- ✅ RSI、MACD表示
- ✅ サポート・レジスタンスレベル表示
- ✅ シグナルアラート機能
- ✅ 初心者向けで使いやすい

---

## 🚀 クイックスタート（5分）

### ステップ1: ファイルをダウンロード

```
GitHub から:
signal-tool/fx_multiframe_analyzer.mq5
をダウンロード
```

### ステップ2: MT5にインストール

```
1. MT5を起動
2. メニュー「ファイル」→「データフォルダを開く」
3. MQL5 → Indicators フォルダを開く
4. fx_multiframe_analyzer.mq5 をここにコピー
5. MT5を再起動
```

### ステップ3: チャートに追加

```
1. チャートを開く
2. メニュー「挿入」→「インジケータ」
3. 「カスタムインジケータ」→「fx_multiframe_analyzer」
4. 「OK」をクリック
```

✅ **完成！チャート左上にシグナルが表示されます**

## 📊 シグナルの見方

### チャートに表示される情報

```
FX Multi-Timeframe Analyzer

4H: 🔼 UPTREND
    RSI: 55.23
    Price: 1.0950

1D: 🔼 UPTREND
    RSI: 65.12

1W: 🔼 UPTREND
    RSI: 72.45

Alignment: ✓ ALL BULLISH
```

### トレンドの読み方

| シンボル | 意味 | 取引シグナル |
|---------|------|-----------|
| 🔼 UPTREND | 上昇トレンド | **買い候補** |
| 🔽 DOWNTREND | 下降トレンド | **売り候補** |
| → RANGE | 横ばい相場 | **待機** |

### Alignment（最重要！）

| Alignment | 意味 | 信頼度 |
|-----------|------|--------|
| ✓ ALL BULLISH | 4H・1D・1W全て買い | ⭐⭐⭐⭐⭐ **最強** |
| ✓ ALL BEARISH | 4H・1D・1W全て売り | ⭐⭐⭐⭐⭐ **最強** |
| ⚠ MIXED | タイムフレーム混合 | ⭐⭐ **弱い** |

## ⚙️ インジケータ設定（初期値で大丈夫）

| 設定項目 | デフォルト値 | 説明 |
|---------|----------|------|
| FastMALength | 9 | 短期移動平均 |
| SlowMALength | 21 | 長期移動平均 |
| MAType | SMA | 移動平均の種類 |
| RSILength | 14 | RSI計算期間 |
| RSIOverBought | 70 | RSI買われすぎ |
| RSIOverSold | 30 | RSI売られすぎ |
| Show4HTrend | ON | 4H表示 |
| Show1DTrend | ON | 1D表示 |
| Show1WTrend | ON | 1W表示 |
| ShowAlerts | ON | アラート表示 |

**推奨:** デフォルト値をそのまま使用してください

## 💡 使い方のコツ

### ✅ おすすめの使い方

```
1. EUR/USD、4時間足で開始
   └─ 最も安定したシグナル

2. 毎日2回確認
   └─ 朝1回、夜1回

3. Alignment が ALL BULLISH/BEARISH なら取引検討
   └─ MIXED は待機

4. RSI 30-70 の範囲内なら売買
   └─ 極端な値では避ける

5. 1回の利益は口座の 1-2%
   └─ 資金管理が重要
```

### ❌ 避けるべき使い方

```
❌ MIXED シグナルで無理やり取引
   └─ 信号が弱い

❌ 経済指標発表時に取引
   └─ ボラティリティが極端に高い

❌ 感情で取引
   └─ ツールの指示に従う

❌ 大きすぎるロット
   └─ リスク管理が大切
```

## 🆘 よくある質問

### Q: インジケータが表示されない

```
A: 以下を確認してください：
1. ファイルは MQL5/Indicators/ に正しくコピーされたか
2. MT5を再起動したか
3. ファイル名に拡張子 .mq5 がついているか
```

### Q: アラートが鳴らない

```
A: MT5の設定を確認してください：
1. メニュー「ツール」→「オプション」
2. 「イベント」タブ
3. アラートをONに設定
```

### Q: どの通貨ペアがおすすめ？

```
A: 初心者向けランキング：
1位: EUR/USD  ← 最も推奨
2位: USD/JPY
3位: GBP/USD
4位: AUD/USD

EUR/USD 4時間足から始めることをお勧めします！
```

### Q: デモアカウントでテストできますか？

```
A: もちろんです！むしろ推奨します：
1. ブローカーのデモアカウントを作成
2. MT5でデモアカウントにログイン
3. インジケータを追加
4. 1ヶ月間デモで取引して検証
5. 成績が良ければリアルアカウントで開始
```

## ⚠️ 重要な注意事項

```
⚠️ これは分析ツールです
   - 100%の勝率を保証しません
   - 過去のパフォーマンスは将来を約束しません

⚠️ 必ずストップロスを設定してください
   - 予期しない損失を防ぐため

⚠️ リスク管理が最重要です
   - 1回の取引リスクは口座資金の 1-2%
   - 無理は禁物

⚠️ デモでテストしてから開始
   - リアルマネーは十分な検証後
```
