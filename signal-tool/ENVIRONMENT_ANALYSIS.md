## 🔄 通貨ペアの相関性

### **相関関係の数学**

```
EUR/JPY ≈ EUR/USD × USD/JPY

つまり:
EUR/JPYが上昇する = 
  ✓ EUR/USD が上昇 AND USD/JPY が上昇
  または
  ✓ EUR/USD が上昇（USD/JPY 横ばい）
  または
  ✓ USD/JPY が上昇（EUR/USD 横ばい）
```

### **実践的な相関性分析**

#### **パターン1: 全て上昇トレンド**

```
EUR/USD: 🔼 UP
USD/JPY: 🔼 UP
EUR/JPY: 🔼 UP

✅ 評価: 最強の買いシグナル
   理由: 全て同じ方向
   
信頼度: ⭐⭐⭐⭐⭐
推奨行動: 強気で買い
```

#### **パターン2: EUR/USD上、USD/JPY下**

```
EUR/USD: 🔼 UP
USD/JPY: 🔽 DOWN
EUR/JPY: → 判断困難

⚠️ 評価: 信号が矛盾している
   理由: EUR/JPY の動きが不確定
   
信頼度: ⭐ 非常に低い
推奨行動: 待機・様子見
```

#### **パターン3: USD/JPY基準で分析**

```
USD/JPY: 🔼 UP （ドル円上昇＝円弱気）
EUR/USD: → 中立
EUR/JPY: 🔼 UP

✅ 評価: ドル高トレンド確認
   理由: 円が売られている
   
信頼度: ⭐⭐⭐⭐
推奨行動: 円売り系（EUR/JPY）で買い
```

## 📊 環境分析のステップ

### **ステップ1: EUR/USD で全体トレンド確認（最重要）**

```
1️⃣ 週足・日足・4時間足を確認
   
   全て UP     → グローバルアップトレンド
   全て DOWN   → グローバルダウントレンド
   混合        → レンジまたは複雑

2️⃣ EUR/USD の Alignment を確認
   
   ALL BULLISH → 強い買いシグナル
   ALL BEARISH → 強い売りシグナル
   MIXED       → 待機
```

### **ステップ2: USD/JPY で円の強弱を確認**

```
USD/JPY UP (円安)
  → ドル買い・円売り
  → EUR/JPY も上昇しやすい
  → 円売り系通貨ペア有利

USD/JPY DOWN (円高)
  → ドル売り・円買い
  → EUR/JPY も下降しやすい
  → 円買い系通貨ペア有利
```

### **ステップ3: EUR/JPY で相関性を確認**

```
EUR/JPY が EUR/USD と USD/JPY の
シグナルと一致しているか確認

✅ 一致している  → シグナル強い
❌ 矛盾している  → 慎重に

例:
EUR/USD: UP
USD/JPY: UP
EUR/JPY: UP ← 全て一致 = 最強シグナル
```

## 📋 実際の取引例

### **シナリオ1: ユーロドル優勢トレンド**

```
現在の状況:
EUR/USD: 
  4H: 🔼 UP, 1D: 🔼 UP, 1W: 🔼 UP
  Alignment: ✓ ALL BULLISH
  RSI: 55（正常）

USD/JPY:
  4H: → RANGE, 1D: 🔼 UP
  トレンド弱い

EUR/JPY:
  4H: 🔼 UP, 1D: 🔼 UP
  EUR/USD の上昇に追従

📊 分析:
  ✅ ユーロが主導的に上昇
  ✅ ドル円は弱い（円買いが入っている）
  ✅ でも EUR/JPY も上昇（ユーロ力強い）

🎯 取引判定:
  推奨: EUR/USD で強気に買い
  確信度: ⭐⭐⭐⭐⭐ 最高
  
  根拠:
  - EUR/USD が最強シグナル
  - EUR/JPY もサポート
  - 複数シグナルが一致
```

### **シナリオ2: 円買い環境**

```
現在の状況:
USD/JPY:
  4H: 🔽 DOWN, 1D: 🔽 DOWN, 1W: 🔽 DOWN
  Alignment: ✓ ALL BEARISH
  RSI: 35（売られすぎ手前）

EUR/JPY:
  4H: 🔽 DOWN, 1D: 🔽 DOWN
  強い下降トレンド

EUR/USD:
  4H: → RANGE, 1D: 🔼 UP
  トレンド弱い（ユーロ単体は上昇）

📊 分析:
  ✅ 円買いトレンド明確
  ✅ USD/JPY が主導（ドル売り）
  ✅ EUR/JPY も下降（円買いが勝っている）
  ⚠️ EUR/USD は上昇（ユーロは強い）

🎯 取引判定:
  推奨: USD/JPY で売り
  確信度: ⭐⭐⭐⭐ 高い
  
  根拠:
  - USD/JPY が強い売りシグナル
  - EUR/JPY も売りで確認
  - 円買い環境明確
```

### **シナリオ3: 信号が矛盾している**

```
現在の状況:
EUR/USD: 🔼 UP (買い)
USD/JPY: 🔽 DOWN (売り)
EUR/JPY: → RANGE (不確定)

📊 分析:
  ✗ 3つのシグナルが矛盾
  ✗ トレンド方向が不明確
  ✗ ノイズの可能性

🎯 取引判定:
  推奨: 全て待機
  確信度: ⭐ 非常に低い
  
  根拠:
  - トレンドが明確でない
  - シグナルが矛盾している
  - リスク・リワード比が悪い
  - 次のシグナルを待つ
```

## 💡 環境分析のコツ

### **✅ すべきこと**

```
✓ EUR/USD をメイン基準にする
  └─ これが全体の基調

✓ USD/JPY で円の強弱を確認
  └─ 円絡みの通貨の動きを予測

✓ EUR/JPY で相関性を確認
  └─ シグナルの一致度をチェック

✓ 3つのシグナルが一致したら強気
  └─ 複数確認で信頼度UP

✓ 矛盾したら待機
  └─ リスク回避
```

### **❌ してはいけないこと**

```
✗ 1つの通貨ペアだけで判断
  └─ 局所的判断になる

✗ USD/JPY だけで全体を判断
  └─ ノイズが多い

✗ EUR/JPY だけで取引
  └─ 相関性を見落とす

✗ シグナルが矛盾している時に無理に取引
  └─ 損失の元

✗ 時間足を混在させて判定
  └─ 4H基準で統一する
```

## ⚠️ 注意事項

### **時間帯による特性の変化**

```
東京時間（9:00-15:00）
  → USD/JPY が活発
  → ユーロドルはやや静か
  → 円がらみが有利

ロンドン時間（16:00-24:00）
  → EUR/USD が活発
  → ドル円も活発
  → 最も流動性高い

ニューヨーク時間（21:00-翌6:00）
  → 全て活発
  → ボラティリティ最高
  → 最も多くのシグナル出現
```

### **経済指標時の注意**

```
❌ 要人発言時は取引を控える
   └─ ボラティリティが極端になる

❌ GDP・インフレ指標発表時
   └─ 予測不可能な動き

❌ 中央銀行金利決定時
   └─ 大きく動く可能性

✅ 通常時に環境分析に基づいて取引
```
