# 📊 経済指標統合ガイド（経済カレンダーと共に監視）

**MT5で経済指標をシグナルツールと並行して表示・監視する方法**

---

## 🎯 目的

3つの通貨ペア（EUR/USD、USD/JPY、EUR/JPY）の経済指標を監視しながら、fx_multiframe_analyzerのシグナルと組み合わせて、より精度の高いトレード判断を行います。

---

## 📈 MT5での経済カレンダー表示方法

### ステップ1: 経済カレンダーを開く

```
MT5メニュー
  ↓
「ツール」→「経済カレンダー」
  ↓
経済カレンダーウィンドウが開く
```

### ステップ2: 通貨別フィルタリング

```
経済カレンダーウィンドウ上部:
  □ USD   ← チェック
  □ EUR   ← チェック
  □ JPY   ← チェック
  □ 他    ← アンチェック

※ これで関連する通貨の指標だけ表示
```

### ステップ3: 重要度フィルタ

```
「カレンダー設定」ボタン
  ↓
「重要度」を選択
  ↓
「High」のみ表示 ← 推奨
```

### ステップ4: ウィンドウ配置

```
推奨レイアウト:

┌─────────────────────────────────────┐
│  MT5チャート領域（3つ並べる）      │
│  EUR/USD | USD/JPY | EUR/JPY        │
├─────────────────────────────────────┤
│  経済カレンダー（下部に常時表示）  │
│  次の経済指標イベント一覧           │
└─────────────────────────────────────┘
```

ウィンドウ分割:
```
1. チャートと経済カレンダーが開いた状態
2. メニュー「ウィンドウ」→「分割」
3. 「2つのウィンドウ」→「上下」を選択
4. 上部にチャート、下部に経済カレンダー
```

### EUR/JPY に影響する指標

⚠️ **重要:** EUR/JPY は EUR/USD と USD/JPY の相関ペアです。
- **EUR が上昇 + ドル円が上昇 = EUR/JPY 大上昇**
- **EUR が上昇 + ドル円が下降 = EUR/JPY 小上昇**

```
監視する指標:
1. ECB 金利発表（EUR の方向性）
2. 米FOMC 金利発表（ドル円の方向性）
3. 日銀 金利発表（ドル円の方向性）
4. 欧州インフレ率（EUR の強度）
5. 米雇用統計（ドルの強度）

→ 上記5つをチェックすれば十分です
```

## ⚡ 経済指標発表時の対応方法

### 発表前（30分前）

```
【発表30分前の対応】

1️⃣ 取引をクローズ
   └─ 持っているポジションを決済
   
2️⃣ チャートをスクリーンショット
   └─ 発表前後の比較用

3️⃣ 指標の「予想値」を確認
   └─ 実際の結果と比較するため
```

### 発表時（瞬間）

```
【発表時刻の対応】

⚠️ 取引禁止時間帯
  ├─ 発表時刻 ±5分間は取引しない
  ├─ ボラティリティが極端に高い
  └─ スリッページが大きくなる

📊 観察モード
  ├─ チャートの値動きを観察
  ├─ シグナルの変化を記録
  └─ 反応パターンを学習
```

### 発表後（15分後）

```
【発表後の対応】

1️⃣ ボラティリティが落ち着くまで待機（5-15分）
   
2️⃣ 新しいシグナルを確認
   ├─ 指標発表により新しいトレンドが発生
   ├─ 既存シグナルが変わったか判定
   └─ ALL BULLISH/BEARISH なら取引検討

3️⃣ 新しいトレード準備
   ├─ 指標の「結果 vs 予想」を分析
   ├─ 相場の反応方向を確認
   └─ 取引タイミング判定
```

### ケース1: 米雇用統計（NFP）発表時

```
【5分後：08:36】

判定: 買いシグナル発生

【取引】
├─ ポジション: EUR/USD 買い
├─ 根拠: 「指標強気 + シグナル一致」
├─ ストップロス: 発表前の安値
└─ テイクプロフィット: 直近レジスタンス
```

## 🚨 危険な経済指標パターン

### ⛔ 取引を避けるべき時間帯

```
① FOMC金利発表時
   └─ ±30分間は取引禁止
   
② 米雇用統計（NFP）発表時
   └─ ±30分間は取引禁止
   
③ ECB金利発表 + 声明文朗読時
   └─ ±20分間は取引禁止
   
④ 日銀金利決定会合の金融政策決定会議
   └─ ±15分間は取引禁止
   
⑤ 複数の重要指標が同時に発表
   └─ その時間帯全体で取引禁止
```

### ⚠️ リスク管理の鉄則

```
【経済指標時のルール】

❌ しては行けないこと
  ├─ 指標発表時に大きなロットで取引
  ├─ スリッページを予測して取引
  ├─ 感情的に急いで取引
  └─ ストップロスなしで取引

✅ すべきこと
  ├─ 指標結果を確認してから取引
  ├─ ボラティリティが落ち着くまで待機
  ├─ シグナルと指標方向が一致してから
  └─ 必ずストップロス設定
```

## 💡 経済指標とシグナルの組み合わせルール

### 強気シグナル（買い）の条件

```
✓ ALL BULLISH シグナル + 買い圧力指標 発表
  └─ 強い買いシグナル ⭐⭐⭐⭐⭐

✓ ALL BULLISH シグナル + ニュートラル指標
  └─ 通常の買いシグナル ⭐⭐⭐

⚠ MIXED シグナル + 買い圧力指標
  └─ 弱い買いシグナル ⭐⭐
```

### 弱気シグナル（売り）の条件

```
✓ ALL BEARISH シグナル + 売り圧力指標 発表
  └─ 強い売りシグナル ⭐⭐⭐⭐⭐

✓ ALL BEARISH シグナル + ニュートラル指標
  └─ 通常の売りシグナル ⭐⭐⭐

⚠ MIXED シグナル + 売り圧力指標
  └─ 弱い売りシグナル ⭐⭐
```

### 待機シグナルの条件

```
❌ MIXED シグナル + 大型指標発表予定
  └─ 指標発表まで待機

❌ 不安定なシグナル + 複数指標重複
  └─ ボラティリティが落ち着くまで待機
```

## 📞 トラブルシューティング

### Q: 経済カレンダーが見つかりません

```
A:
1. MT5を起動
2. メニュー「ツール」を確認
3. 「経済カレンダー」が見えない場合は
   ツール → オプション → イベント から設定
```

### Q: 指標発表時の値動きが大きすぎます

```
A:
1. これは正常です（ボラティリティが高い）
2. 発表±15分は取引を避けてください
3. ボラティリティが落ち着くまで待機
4. 新しいシグナルを確認してから取引再開
```

### Q: 指標とシグナルが反対方向です

```
A:
1. 市場がサプライズ反応している
2. その場合は「待機」を推奨
3. 新しいシグナルが形成されるまで観察
4. 後で「なぜそうなったのか」を分析記録
```

### Q: 全ての指標を監視すべきですか？

```
A: いいえ。以下だけで十分です：

EUR/USD を監視する場合:
  1. FOMC金利発表
  2. ECB金利発表
  3. 米雇用統計
  4. 欧州インフレ率
  5. 米GDP

USD/JPY を監視する場合:
  1. FOMC金利発表
  2. 日銀金利発表
  3. 米雇用統計
  4. 日本インフレ率

EUR/JPY を監視する場合:
  ↑ 上記2つを両方監視すれば十分
```
