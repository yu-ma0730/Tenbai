# 🎯 3通貨ペア同時監視セットアップガイド

## 📊 目標

MT5で以下の3つの通貨ペアを同時に監視する環境を構築します。

```
1. EUR/USD（ユーロドル）   ← メイン
2. USD/JPY（ドル円）       ← サブ
3. EUR/JPY（ユーロ円）     ← 確認用
```

---

## 🚀 クイックセットアップ（15分）

### **ステップ1: 3つのチャートウィンドウを開く**

```
MT5メインウィンドウ

1️⃣ EUR/USD チャート開く
   メニュー「ファイル」→「新しいチャート」
   → EUR/USD を選択

2️⃣ USD/JPY チャート開く
   メニュー「ファイル」→「新しいチャート」
   → USD/JPY を選択

3️⃣ EUR/JPY チャート開く
   メニュー「ファイル」→「新しいチャート」
   → EUR/JPY を選択
```

### **ステップ2: 全て4時間足に統一**

```
各チャートで:
  時間足ボタン → H4（4時間足）を選択

※ 全て4時間足に統一することが重要
```

### **ステップ3: 各チャートにインジケータを追加**

```
各チャートで以下を実行:

メニュー「挿入」
  ↓
「インジケータ」
  ↓
「カスタムインジケータ」
  ↓
「fx_multiframe_analyzer」を選択
  ↓
「OK」
```

✅ **完成！3つのチャートにシグナルが表示されます**

## 💾 チャートの保存と再利用

### **セットアップを保存する**

一度セットアップしたら、保存して毎回使えます。

**保存方法:**
```
1. 3つのチャートを完成させる
2. メニュー「ファイル」→「チャートの保存」
3. 名前を付ける例: "FX_3Pairs_Analysis"
4. 保存
```

**再利用方法:**
```
1. MT5起動
2. メニュー「ファイル」→「チャートを開く」
3. 保存したファイルを選択
4. ✅ すぐに3つのチャートが同時に開く
```

## 📊 同時監視での分析方法

### **方法1: 順序に従って分析**

```
Step 1: EUR/USD を確認
        ↓
        (全体トレンド判定)
        ↓
Step 2: USD/JPY を確認
        ↓
        (円の強弱判定)
        ↓
Step 3: EUR/JPY を確認
        ↓
        (相関性確認)
        ↓
最終判定: 取引OK? 待機?
```

### **方法2: 矛盾チェック**

```
チェック項目:

□ EUR/USD 上昇なら
  → USD/JPY も上昇しているか?
  
□ USD/JPY 上昇なら
  → EUR/JPY も上昇しているか?
  
□ 全て上昇なら
  → 強い買いシグナル ✓
  
□ 1つだけ異なるなら
  → 信号弱い ⚠
  
□ 全て異なる方向なら
  → 待機 ❌
```

## 🛠️ トラブルシューティング

### **Q: 3つのチャートをどうやって並べるの？**

```
A:
Windows の場合:
  1. チャート1・2・3を開く
  2. メニュー「ウィンドウ」
  3. 「分割」→「3つの水平」

Mac の場合:
  1. チャート1・2・3を開く
  2. 各チャートウィンドウをドラッグして配置
```

### **Q: インジケータが1つのチャートだけ表示されない**

```
A:
  1. MT5を再起動
  2. インジケータを再度追加
  3. ファイルが正しい場所にあるか確認
```

### **Q: 4つ目の通貨ペアも監視したいが？**

```
A: 推奨しません
  理由:
  - 3つで十分な分析が可能
  - 4つになると複雑になる
  - 初心者には難しい
  
  余裕があれば:
  - GBP/USD を追加可
  - ただし時間がかかる
```
