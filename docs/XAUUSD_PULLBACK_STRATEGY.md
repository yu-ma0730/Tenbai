# P4 Method - XAUUSD Pullback Selling Strategy

## 戦略概要

4時間足のパーフェクトオーダー（PO）が形成中に、1時間足の反発ポイントでのショート（戻り売り）を狙う戦略です。

## コア理論

### 1️⃣ 4時間足パーフェクトオーダー（PO）

**ショート条件**
```
EMA80 > EMA40 > EMA20 > EMA10（4時間足）
```

このPOが崩れるまでの間、ショート取引が有効です。

### 2️⃣ EMA乖離管理

```
4時間足EMA10との乖離が発生
  ↓
乖離を埋める形で上昇
  ↓
各反発ポイントで抵抗を受ける
  ↓
ショート
```

**乖離を埋める上昇中にショート狙い**

### 3️⃣ 反発ポイント（3段階）

| # | ポイント | 説明 |
|---|---------|------|
| ① | 1時間足EMA40 | 最初の抵抗ライン |
| ② | 4175.67 | 固定レジスタンス |
| ③ | 1時間足EMA80 | 最終防衛ライン |

**EMA80はトレンドの最終防衛ライン**
- このレベルを上抜けるとトレンド転換期
- 注意が必要

## シグナル検出

### 下降シグナル（3種類）

#### 1. **上髭反発** （ウィック拒否）
```
ローソク足の上髭が長い
  ↓
ボディより大きな上髭
  ↓
売り圧力が強い = ショートシグナル
```

#### 2. **ピンバー** （逆ハンマー）
```
小さなボディ + 長い下髭
  ↓
反発ポイントで形成
  ↓
反転を示唆
```

#### 3. **毛抜き天井** （インバースピンサー）
```
2本連続で同じ高さ（ハイ）
  ↓
ボディは異なる
  ↓
売り手と買い手の均衡破綻
  ↓
下降へ
```

## 運用ルール

### ✅ エントリー条件（すべて満たす必要あり）

1. **4時間足POが形成中**
   ```
   EMA80 > EMA40 > EMA20 > EMA10
   ```

2. **1時間足で反発ポイント接近**
   ```
   ① EMA40 付近（±50pips）
   ② 4175.67 付近（±50pips）
   ③ EMA80 付近（±50pips）
   ```

3. **下降シグナル確認**
   ```
   上髭反発 OR ピンバー OR 毛抜き天井
   ```

4. **EMA乖離が健全**
   ```
   4時間足EMA10との乖離 < 0.15%
   ```

5. **経済指標時間帯ではない**
   ```
   14:00-17:00 US時間を避ける
   ```

### ❌ 終了条件

1. **4時間足POが崩れる**
   ```
   PO消滅 → 取引中止
   ```

2. **1時間足EMA80を上抜ける**
   ```
   トレンド転換期 → ポジション決済
   ```

3. **EMA乖離が大きすぎる**
   ```
   乖離 > 0.15% → シグナルをスキップ
   ```

## リスク管理

### 損切設定
```
SL = 反発ポイント + 100pips
   （レジスタンスの直上）
```

### 利確設定
```
TP = エントリー価格 - (SL - エントリー) × 1.0
   （リスク・リワード 1:1）
```

### ロットサイズ計算
```
ロット = (口座残高 × 0.75%) / (SLまでのpips × tick値)
```

**超重要**: リスクを 0.75% に抑える理由
- スプレッド対策（金は1.5～3.0 pips）
- 騙し反転対策
- 長期的な継続性確保

## 注意点

### 🚨 重要ポイント

1. **100% 勝てる戦略ではない**
   ```
   私の分析も100%ではないので
   ハイレバ全力はNG
   ```

2. **コツコツドカンの逆を目指す**
   ```
   小さな利益を継続的に
   + たまに大きな利益
   = 長期的な成功
   ```

3. **経済指標に注意**
   ```
   新規失業保険申請件数
   PPI（生産者物価指数）
   発表時間帯 ±2時間は避ける
   ```

4. **EMA80は最終防衛ライン**
   ```
   上抜けるとトレンド転換期
   ポジション持越し厳禁
   ```

5. **相場観の確認**
   ```
   4時間足のEMA10との乖離を常に監視
   乖離が埋まるまでの期間が取引機会
   ```

## 戦略の3つの選択肢

**あなたの分析と納得に合わせて採用:**

### 選択肢① 反発ポイントまでのロング
```
①→②→③ への上昇を狙う
リスク: 小さい
利益: 小さい
向き: 保守的
```

### 選択肢② 反発ポイントまで待つ
```
ポイント到達後のシグナル待ち
リスク: 中程度
利益: 中程度
向き: バランス
```

### 選択肢③ 反発ポイントでのショート
```
推奨戦略
リスク: 中～高
利益: 中～高
向き: アグレッシブ
```

**各自の見たタイミングや分析と照らし合わせて、納得できた部分だけ採用してください。**
